## Descripción

Este repositorio contiene el Trabajo Práctico Integrador realizado para la materia Organización Empresarial.

Para el proyecto se eligió analizar el proceso de atención al cliente y gestión de pedidos de la empresa Mimbrería Fleming. Actualmente gran parte de las consultas se realizan por WhatsApp Business y son respondidas manualmente por el personal.

A partir del análisis realizado, se propuso una mejora mediante la implementación de un chatbot capaz de responder consultas frecuentes sobre productos, precios, stock, medidas, formas de pago y envíos.

## Herramientas utilizadas

* WhatsApp Business
* Python (propuesto para el chatbot)
* Excel como base de datos simulada
* BPMN 2.0
* GitHub

## Archivos incluidos

* Trabajo_Practico_Integrador.pdf
* Base_Datos_Mimbreria.xlsx

## Objetivo

El objetivo principal del trabajo fue aplicar los conceptos vistos en la materia para analizar un proceso real, detectar oportunidades de mejora y proponer una solución de automatización que permita reducir tareas repetitivas y mejorar la atención al cliente.
