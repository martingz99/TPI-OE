# Descripción

Este repositorio contiene el Trabajo Práctico Integrador realizado para la materia Organización Empresarial.

Para el proyecto se eligió analizar el proceso de atención al cliente y gestión de pedidos de la empresa Mimbrería Fleming. Actualmente gran parte de las consultas se realizan por WhatsApp Business y son respondidas manualmente por el personal.

A partir del análisis realizado, se propuso una mejora mediante la implementación de un chatbot capaz de responder consultas frecuentes sobre productos, precios, stock, medidas, formas de pago y envíos.

Como complemento al modelado realizado, se desarrolló un prototipo funcional en Python que permite simular la interacción del chatbot desde la consola de Visual Studio Code. El programa consulta una base de datos simulada en Excel, valida información ingresada por el usuario, contempla caminos felices e infelices y registra pedidos siguiendo la lógica definida en el diagrama BPMN.

# Funcionalidades del chatbot

* Consulta de productos disponibles.
* Consulta de precios, stock y medidas.
* Validación de existencia de productos.
* Detección de productos sin stock.
* Registro de pedidos.
* Selección de forma de pago.
* Gestión de envíos.
* Validación de datos ingresados por el usuario.
* Implementación de máquina de estados para controlar la conversación.

# Objetivo

El objetivo principal del trabajo fue aplicar los conceptos vistos en la materia para analizar un proceso real, detectar oportunidades de mejora y proponer una solución de automatización que permita reducir tareas repetitivas y mejorar la atención al cliente.

Asimismo, se buscó representar el proceso mediante diagramas BPMN, diseñar una base de datos simulada, documentar el funcionamiento del sistema y desarrollar un prototipo funcional que refleje la lógica propuesta para el chatbot.
